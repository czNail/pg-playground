关于这个实验台 使用提示与边界

真实的 SQL，独立的本地环境。基于 PGlite / WebAssembly，支持 PostgreSQL 的查询、索引、事务和执行计划。每位访客的数据独立，不会自动同步到其他设备。

运行与分析。支持多条 SQL 和选区执行。EXPLAIN / ANALYZE 每次分析一条语句；ANALYZE 按钮仅做只读分析。手工输入的 SQL 按原意执行，包括 EXPLAIN ANALYZE 写入语句。事务出错时可执行 ROLLBACK 恢复。

结果与性能。每条语句最多展示、导出前 1,000 行，结果按每页 100 行浏览。运行耗时包含浏览器与本地存储开销，适合学习计划结构，不代表服务器 PostgreSQL 的性能。运行时限可选 5 秒至 5 分钟或不限，也可点击“停止查询”。停止或超时后自动恢复连接，保留最近保存的数据；未完成事务和会话设置会清除。多语句中已提交的内容请先检查，避免重复写入。

本地保存。同一浏览器一次允许一个标签页使用持久化数据库。临时模式的数据在页面关闭后消失，不会覆盖本地数据库。可导入、保存 SQL 文件；CSV 导出只包含当前所选结果集的前 1,000 行。
